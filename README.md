# WARLORD 伝令の戦場

中世ヨーロッパの戦場で、将として前線に立ちながら伝令で全軍を動かすブラウザゲーム（Three.js）。

**遊ぶ:** https://tsuutantsuutan.github.io/warlord/

- 命令は伝令が馬で届ける。遠い部隊ほど遅く、伝令が捕まると届かない
- 敵は味方の視界内にいるときだけ見える
- 鎧8種・武器6種（博物館の実物写真を元に作成。出典は `ref/SOURCES.md`）
- 陣形7種（Q＋1〜7）、乗馬（E）、三人称（V）
- ソロ（CPU）／オンライン1対1（招待URL `?room=コード`）

## 操作
WASD 移動 / 左クリック 攻撃 / 右クリック 防御 / 1〜0 部隊選択 / F 移動 / C 突撃 / H 待機 / R 集結 / Q＋数字 陣形 / Tab 地図 / E 乗り降り / V 視点
